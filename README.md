# 蚕CHANNEL 体長チェック

Windows 11向けの無料・ローカル解析アプリです。起動するファイルは **蚕チェック.bat** の1本です。プログラム更新と必要なライブラリの準備もこのBATで行います。手順は [ONE_CLICK.md](ONE_CLICK.md)、学校用は [SCHOOL.md](SCHOOL.md) を参照してください。

## 全アーカイブの自動収集・解析

上段の「アーカイブを自動収集・解析」から開始できます。各LIVEから画像を取り出して、同じ解析処理へ渡し、検証ZIP・結果・改善対象をBATフォルダ内のdata/archive_batchへ保存します。途中停止後の再開、次回起動時の自動再開にも対応します。手順・保存形式・クラウドでの取得制限は[ARCHIVE_AUTOMATION.md](ARCHIVE_AUTOMATION.md)を参照してください。自動再学習とモデルの自動採用はこの版には含みません。メイン画面の「改善用ZIPを作る」で、保存済みの画像から最大100枚を選び、送信用ZIPへ自動分割できます。処理済み履歴の学校版への反映と、モデル更新時の元画像再利用にも対応します。

## 自動検出・頭数推定・体長推定

既定の「自動計測（1〜5齢）」では、画像・録画・カメラを開くと解析を開始します。録画とカメラは処理が終わり次第、次のフレームを解析します。大きい画像も分割して拡大探索し、複数の画像で見つかった同じ個体をまとめます。小さい体は明暗補正と背景除外も使います。明るい蚕・暗い蚕の切替は不要です。

- 緑の線：体の曲がりに沿う中心線から計算した全長の推定。
- 黄の点線：全長を保留した個体の、連続して見えている部分だけの長さ。重なりのあいまいな範囲を除き、離れた部分を足しません。
- 番号付きの個体：画面内の推定頭数に含めます。体長が測れない個体にも番号を付けます。
- 橙の輪郭：頭数には含め、輪郭の欠け、重なり、見切れ等のため全長を保留。見える部分の値も全長平均には含めません。
- 灰色の候補：頭数に含めていない要確認領域。「要確認の候補も表示」で切り替えられます。
- 平均・最小・最大は測定できた個体だけの値。候補数は飼育頭数と一致するとは限りません。

**1〜5齢の代表画像で動作を確認した試験版です。全齢・全背景で十分な認識精度を達成した版ではありません。** 特に孵化直後、茶色い餌（人工飼料の可能性・種類未確定）に紛れる1齢、葉に隠れた体は追加検証・改善が必要です。検証内容は [ACCURACY.md](ACCURACY.md) に記載します。

今回は無料の外部学習済み蚕専用モデル YOLOv8-DSRI を使用し、小さい体の誤検出除外には蚕CHANNELの自作テクスチャモデルも使います。外部モデルの使用を画面・ソースで明記し、従来の自作モデルも解析方式のメニューに残しています。ライセンスと対応するソースは [THIRD_PARTY.md](THIRD_PARTY.md) を参照してください。画像を外部AIへ送信する処理はありません。

## 使い方

1. いつもの「蚕チェック.bat」を起動し、更新と初回モデル取得を待ちます。
2. 「画像／録画を開く」か「カメラ接続」を選びます。OBS使用中はOBSの仮想カメラを入力にする方法もあります。
3. mmで表示する場合は、同じ高さの定規などの既知の長さを入力し、「基準線を2点指定」で両端をクリックします。未設定ならpxで表示します。
4. カメラ・録画の設定操作後は「一時停止／再生・自動に戻る」で再開します。

右側の黒いOBS情報欄は自動で測定範囲から外す処理があります。配置が合わない場合は「測定範囲を2点指定」で容器だけを囲みます。葉の下や重なった部分の長さは推測で補いません。中心線は画像平面上の長さであり、持ち上がった体や高さの違いによる誤差があります。

## 保存・配信

体長CSVはBATのフォルダ内の `data/measurements.csv`、頭数CSVは `data/counts.csv`、個体別サイズCSVは `data/individual_sizes.csv`、検証用ZIPは `data/samples` です。「保存先を開く」「ZIP保存先を開く」から開けます。個体別CSVの番号はそのフレーム内だけの仮番号です。専用ライブラリ・キャッシュ・ログもBATのフォルダ内に置きます。AppDataへ新しいアプリデータを保存しません。

CSVの自動推定は `method=auto_instance_estimate`。設定欄にモデルの出所、ハッシュ、検出数、各候補の確信度・保留理由も保存します。手動計測の行と区別できます。`measurements.csv`のcountは従来どおり体長を測れた個体数です。`counts.csv`には画面内の推定頭数・頭数の要確認候補数・全長を測れた数・全長保留数を別々に保存します。`individual_sizes.csv`は各個体のfull_length（全長）とvisible_segment_length（見える連続部分）を分けます。全長が分からない欄は空欄で、0や部分長を代入しません。length_statusがvisible_segment_estimateの値は全長ではありません。静止画は解析ごと、映像は約10秒間隔で記録します。0匹分の行も残し、測定不能な時間を隠しません。

OBSのテキストソースで `data/obs_status.txt` を読むと、推定頭数・体長平均・何匹分の推定か・更新時刻を表示できます。表示の輪郭は実際に解析したフレームに重ねます。個体番号の永続追跡や、同一個体の成長率の算出はまだありません。見えている頭数の推定で、葉の下の個体を含む飼育総数とは一致しないことがあります。既存の温湿度Python GUIへの接続はこの版では変更していません。

## 開発・配布

自宅用ブランチは `parsonal`、学校用は `school`。学校用は `X:\python 3.12\python.exe` を使います。GitHubの署名付きフィードからプログラムを取得し、初回は固定ハッシュの約7MBの検出モデルも取得します。以後はキャッシュを再利用します。通信できない場合は準備済みの手元の版で起動します。

実装は Python / OpenCV / PyTorch。推論専用コードは `kaiko_dsri`、個体マスクと中心線は `instance_detector.py` / `instance_geometry.py`、画面は `app.py`。`python -m unittest discover` で検証できます。学習画像・録画・教師ラベル・測定記録・署名秘密鍵は公開パッケージへ含めません。
