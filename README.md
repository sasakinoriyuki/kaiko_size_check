# 蚕CHANNEL 体長チェック — 学校用・フォルダ内保存

学校版のコードと更新履歴は、この **`school` ブランチ**で管理します。

## 学校PCで使う

[学校用ZIPをダウンロード（Google Drive）](https://drive.google.com/file/d/1bZ5cXSgn9LUENCZuID4UPICrWKKSJZZu/view?usp=drivesdk)

1. 使いたい、書き込み可能なフォルダへZIPを「すべて展開」します。
2. 展開したフォルダの **蚕チェック.bat**をダブルクリックします。
3. 初回の準備後にアプリが起動します。次回もこのフォルダの同じBATから起動します。

使用するPythonは **`X:\python 3.12\python.exe`** です。初回はライブラリ取得のためネット接続が必要で、起動時はX:ドライブへアクセスできる必要があります。

## 保存場所

アプリ・ライブラリ・記録は、展開したフォルダの中に保存します。AppDataへ学校版をインストールしません。

| ファイル | 展開したフォルダからの場所 |
| --- | --- |
| 検証用ZIP | `data\samples` |
| 測定記録CSV | `data\measurements.csv` |
| ライブラリ・キャッシュ・作業用一時ファイル | `runtime` |
| 起動ログ | `logs` |

「手動で体長をなぞる」の下にある **「保存したファイル」** に、ZIP保存・ZIP保存先を開く・保存先を開く・パスをコピーをまとめました。実際の保存場所も欄内に表示します。

以前の学校版のdataがAppDataにあれば、初回に読み取り、新しいdataへコピーします。元の記録は削除せず、コピー先の同名ファイルも上書きしません。**旧ショートカットは旧版を開くため、新しく展開したフォルダのBATを使ってください。**

詳しい操作は [SCHOOL.md](SCHOOL.md) にあります。
