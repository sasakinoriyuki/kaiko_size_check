# 蚕CHANNEL 体長チェック — 自宅用

**起動するのは「蚕チェック.bat」1本です。** 初回にプログラムと自作モデルをGitHubから取得し、必要なライブラリを準備します。次回も同じBATで更新確認・準備・起動を行います。

## 起動する

[起動用BATだけのZIPをダウンロード](https://drive.google.com/file/d/1qrRdkZ1P9A86-PahrpfL3fekkhIvbanM/view?usp=drivesdk)

1. ZIPを使いたいフォルダへ「すべて展開」します。
2. **蚕チェック.bat**をダブルクリックします。初回はネット接続が必要です。
3. 以後も同じBATで起動します。app.pyの入れ替えや別のセットアップBATは不要です。

今まで使っていたBATは、今回だけ新しいものへ入れ替えてください。GitHubの「Code → Download ZIP」を使う場合も、展開したフォルダの同じBATが入口です。

使える64bit版Python 3.12を利用し、なければPython公式の検証済みインストーラーで専用環境を準備します。管理者として実行する必要はありません。

## 更新と保存

更新先は **parsonal** ブランチの署名付き配布案内です。新しい配布版があれば、署名・SHA256・内容を確認して更新します。PyTorchなどは、その配布版が指定する動作対象の版へ自動で合わせます。初回に自動準備するのはCPU版です。

通信できないときは準備済みの版で起動します。新しいライブラリ環境は別に用意し、更新に失敗したときは以前の版へ戻します。起動中に更新が見つかった場合は、アプリを閉じると処理を続けます。画像や測定記録を送信する機能はありません。

アプリ・ライブラリ・記録はBATと同じフォルダの中に置きます。保存ZIPは `data/samples`、CSVは `data/measurements.csv`、ライブラリ・キャッシュは `runtime`、起動ログは `logs` です。「保存したファイル」欄からフォルダを開いたり、パスをコピーできます。以前の記録が見つかった場合は初回にコピーします。

## 現在の配布版

**2026.11.08-online1**（配布番号11）。自作モデルはv7で、自動体長・頭数は未完成です。

126件の自動テスト、PowerShellでの署名・展開・初回取得・オフライン処理、Linuxの実GUIで両方の版の起動・署名付き更新・記録の保持を確認しています。Windows実機での新しいオンライン初回導入は未確認です。

配布パッケージにはプログラムと自作モデルを含みます。撮影画像・録画・教師ラベル・測定記録・署名用秘密鍵は含めません。パッケージと署名付き案内を `.updates` に置き、検証済みの配布パッケージを更新すると次回起動時から利用者へ反映されます。
